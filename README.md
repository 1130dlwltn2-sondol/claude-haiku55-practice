## 책 소개

Anthropic이 2026-10-07에 공개한 Claude Haiku 5.5를 실무의 반복 텍스트 업무에 적용하는 방법을 다룬 교재다. 모델을 고르는 기준부터 요약·분류·추출 실습, 품질 평가표, 토큰과 비용 계산, 실패에 대비한 라우팅 설계까지 한 권으로 연결한다. 모든 실습은 가상의 합성 데이터로 진행되며, 복사·붙여넣기만으로 따라할 수 있다.

## 독자

- 직장인, 1인 개발자, 반복 텍스트 업무가 많은 실무자
- 선수 지식: 기본은 복사·붙여넣기만 필요. API 실습은 키 관리·JSON·간단한 Python 지식이 있으면 유리하다.

## 구성

- 표지, 도서 소개, 학습 준비, 목차
- 1장 Haiku·Sonnet·Opus를 고르는 기준
- 2장 실습 환경과 안전한 샘플
- 3장 빠르고 정확한 요약
- 4장 분류와 정보 추출
- 5장 품질 평가표 만들기
- 6장 토큰과 비용 계산
- 7장 모델 라우팅과 실패 대안
- 8장 완성 프로젝트: 문의 분류 업무팩
- 실습 정답/예시, FAQ, 참고 자료, 마지막 안내

## 저장소 구조

- book.md: 전체 통합 원고
- chapters/01.md~08.md: 장별 원고
- pages/: 위키독스 연동용 페이지 순서 배치 (연동은 저자 검토 전까지 수행하지 않음)
- project/: 최종 프로젝트 5개 파일 (README, prompts, results, checklist, references)
- data/sample_synthetic_inquiries.csv: 실습용 가상 문의 12건 (utf-8-sig)
- assets/: 표지, 개념도
- references.md: 참고 자료 목록
- QA_REPORT.md: 품질 점검 보고서

## 주의사항

- 본 교재는 작성 기준일(2026-10-11)의 기능을 설명하며, 실제 화면·가격·이용 조건은 달라질 수 있다.
- 가격은 2026-10-11 공식 문서 기준으로 표기했다. 실제 사용 전 공식 문서를 다시 확인한다.
- 벤치마크 수치는 공급사 발표 수치이며 원본 재배포를 하지 않는다.
- 미확인 기능은 단정하지 않고 미확인으로 표기했다.
