# 문의 분류 업무팩 (최종 프로젝트)

## 목표

가상의 고객 문의 12건을 Haiku 5.5로 자동 분류하고, 품질과 비용을 검증하는 업무 절차를 문서화한다. 이 프로젝트는 책 1~7장의 실습 산출물을 하나로 묶은 결과물이다.

## 입력 자료

- data/sample_synthetic_inquiries.csv (가상 문의 12건)
  - 열: id, inquiry, gold_label
  - gold_label 분포: 배송 3건, 결제 4건, 사용법 3건, 기타 2건
  - 전부 가상의 문장이며 실존 인물·업체와 무관하다
  - 파일 첫머리에 UTF-8 BOM이 있으므로 읽을 때는 utf-8-sig 인코딩을 쓴다
- 분류 프롬프트 v1 (project/prompts.md)
- 정답표: gold_label 열 (평가 단계에서만 사용)

## 재현 절차

1. CSV에서 inquiry 열 12건을 복사한다. gold_label 열은 이 단계에서 제외한다.
2. prompts.md의 분류 프롬프트 v1을 채팅형 UI에 입력하고 결과를 JSON으로 받는다.
3. 결과 JSON을 results.md의 비교표 형식으로 정리한다.
4. gold_label 정답표와 대조해 맞음·틀림·판단보류를 표시하고 정확도를 계산한다.
5. checklist.md의 점검 항목을 확인하고 비용 계산표의 기준일(2026-10-11)을 기록한다.

## 산출물

- prompts.md: 사용한 프롬프트와 버전
- results.md: 결과와 수동 검증
- checklist.md: 권한·비용·오류·출처 점검
- references.md: 사용한 공식 자료

## 기준일과 주의사항

- 단가·기능은 2026-10-11 공식 문서 기준이다. 실제 적용 전 공식 문서를 다시 확인한다.
- 실습에는 합성 데이터만 사용한다. 실제 고객 정보·API 키를 파일에 넣지 않는다.
