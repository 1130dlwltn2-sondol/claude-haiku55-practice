# 권한·비용·오류·출처 점검

## 권한 점검

- [ ] 실습에 실제 고객 정보·개인정보를 사용하지 않았는가 (합성 데이터만 사용)
- [ ] API 키를 코드·문서·채팅에 직접 적지 않았는가
- [ ] 키는 환경 변수나 비밀 저장소에 보관하는가
- [ ] 결제 한도와 사용량 알림을 설정했는가

## 비용 점검

- [ ] 단가 기준일을 기록했다 (2026-10-11 공식 문서 기준)
- [ ] 단가는 100만 토큰당 단위로 계산했는가
- [ ] 프롬프트 길이 구간(10만 토큰 기준)을 확인했는가
- [ ] 캐시 적용 조건(최소 512토큰)을 확인했는가
- [ ] Batch 할인은 대기 후 일괄 처리 조건에서만 적용했는가
- [ ] 단가 인하율과 실제 청구 비용 절감률을 구분해서 말하는가

## 오류 점검

- [ ] 분류 입력에서 gold_label을 제외했는가
- [ ] 결과 JSON의 건수(12건)와 형식을 확인했는가
- [ ] 판단보류를 남용하지 않았는가
- [ ] 운영 중단 조건 3개가 문서에 있는가
- [ ] 프롬프트에 버전 번호가 붙어 있는가

## 출처 점검

- [ ] 외부 자료에 제목·발행처·URL·열람일을 표시했는가
- [ ] 벤치마크 수치는 공급사 발표 수치임을 명시했는가
- [ ] 미확인 기능(S4 시스템 카드 세부 내용)은 미확인으로 표기했는가
- [ ] 발표일(2026-10-07)과 작성 기준일(2026-10-11)을 분리해서 썼는가
