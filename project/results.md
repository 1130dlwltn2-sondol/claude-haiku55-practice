## 수동 검증 기록

- 정확도: 11/12 = 91.7%
- 누락: 0건 (id T001~T012 전부 존재)
- 형식 준수: JSON 배열 구조 정상, label 값 4종 이내
- 혼동 범주: 사용법→기타 1건
- 수정 시간: T010 1건을 사람이 재분류하는 데 약 1분 (가상 기록)

## 검증 방법

1. AI 분류 결과의 id가 12건 모두 있는지 센다.
2. gold_label 정답표와 한 건씩 대조한다.
3. 틀린 건의 reason 필드를 읽고 분류 기준의 어디가 모호했는지 적는다.
4. T010의 경우 "버튼이 눌리지 않아요"는 기기·앱 사용 중 문제이므로 사용법(문제 해결) 범주가 정답표 기준에 맞다. 분류 기준 문장에 "기기·앱 오류 신고는 사용법"을 추가하면 개선된다.

## 한계

- 12건은 소규모 표본이므로 이 정확도를 일반화할 수 없다.
- 가상 데이터 기준이므로 실제 문의에서는 분포와 난도가 달라진다.
